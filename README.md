# Mariano Alvez

**Senior Backend / Full Stack Developer · Arquitectura de software e integraciones de IA**

Desarrollo productos web y mobile con foco en backend, APIs e integración de sistemas. Mi base es **TypeScript, Node.js y NestJS**, junto con **Angular y Flutter** para construir soluciones de principio a fin.

Trabajo en arquitectura de aplicaciones, BFFs, microservicios, integraciones de pagos y automatización de procesos. También desarrollo herramientas e integraciones de IA aplicadas a necesidades de producto. Me interesa que las soluciones sean comprensibles, mantenibles y útiles para quienes las usan.

## Áreas de trabajo

- **Backend e integraciones:** APIs REST, servicios BFF, webhooks, autenticación, permisos y sincronización entre sistemas.
- **Arquitectura y entrega:** decisiones técnicas, organización del código, modelado de datos, pruebas y evolución de aplicaciones existentes.
- **Web y mobile:** interfaces con Angular y aplicaciones con Flutter conectadas a servicios backend.
- **IA aplicada:** integración de modelos y herramientas de IA con aplicaciones, APIs y procesos de negocio.
- **Formación técnica:** experiencia acompañando a estudiantes de backend y explicando fundamentos, decisiones y buenas prácticas.
